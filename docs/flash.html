Install AirTrack on your device

Plug a Waveshare ESP32-C6-LCD-1.47 into this computer with a USB-C data cable and press Install. The firmware is written straight from this page over USB — nothing to download, no toolchain, no command line.

Release notes

This browser cannot talk to USB devices. Use Chrome, Edge, or Opera on a desktop computer — Web Serial is not available in Firefox, Safari, or on phones and tablets. You can still install with esptool.
This page must be opened over HTTPS for the browser to allow USB access.
 Takes about a minute.

This erases the device. A first install writes the bootloader, partition table and firmware, and the installer offers to erase everything else — saved Wi-Fi, location and options. Say yes on a new or second-hand device. On a device that is already running AirTrack you normally do not need this page at all: use Updates → Check for updates on its own dashboard, which keeps every setting.

After it finishes

  1. The display comes up and the device starts its own Wi-Fi hotspot, AirTrack-XXXX, with the password shown on screen.
  2. Join that hotspot from a phone or laptop; the setup page opens by itself (or visit http://192.168.4.1).
  3. Pick your home Wi-Fi and enter its password. Setting the tracking location is optional — leave it blank and the device starts around Seattle–Tacoma International until you set the real position.
  4. The LCD then shows the address of the dashboard on your network. Open it to set location, radius, brightness, the night schedule and SD logging.

From then on the device updates itself: Updates → Check for updates on the dashboard installs new releases over the air into its spare firmware slot, and rolls back automatically if an image fails to start.

If the device is not offered

  • Use a data USB-C cable. Many charge-only cables carry no data lines and the device will never appear in the port list.
  • Plug into the board's USB-C port and pick the entry that appears when you plug it in — on Windows it looks like USB Serial Device (COMn), on macOS/Linux like USB JTAG/serial debug unit.
  • If it still will not connect, hold the BOOT button while plugging the cable in, then release it and press Install again.
  • Close anything else using the port (Arduino IDE, a serial monitor, another copy of this page).
Install manually instead

The same image can be written with esptool:

esptool.py --chip esp32c6 -b 460800 write_flash 0x0 airtrack-factory.bin
